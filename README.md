# Рабочие дни

Задача H из контеста: в календаре месяц из `n` дней записан строками по `m` дней (недели). Первое число месяца приходится на `k`-й день недели. Рабочими объявляются числа из самой большой по площади прямоугольной области, состоящей из рядом стоящих чисел. Нужно вывести количество рабочих дней.

## Условие

- Ограничение времени: 1 секунда
- Ограничение памяти: 256 МБ
- Ввод: стандартный ввод или `input.txt`
- Вывод: стандартный вывод или `output.txt`

**Ввод.** Три целых числа `n`, `m`, `k` через пробел: число дней в месяце, в неделе и номер дня недели, на который приходится первое число месяца. 1 ≤ m < n ≤ 100, 1 ≤ k ≤ m.

**Вывод.** Одно целое число: количество рабочих дней в месяце.

### Примеры

| Ввод        | Вывод |
|-------------|-------|
| `39 10 6`   | `30`  |
| `12 5 2`    | `8`   |
| `13 5 2`    | `9`   |
| `15 4 1`    | `12`  |

## Идея решения

Ограничения маленькие (n ≤ 100), поэтому хватает прямого перебора.

1. Строим сетку календаря. День `d` стоит в позиции `p = d - 1 + (k - 1)`, то есть в строке `p // m` и столбце `p % m`. Всего строк `(n + k - 2) // m + 1`.
2. Клетки, в которых стоят числа, помечаем как заполненные. Пустыми остаются клетки в начале первой строки (до `k`-го дня) и в конце последней строки.
3. Перебираем все прямоугольники сетки и оставляем только те, у которых все клетки заполнены. Среди них берём максимальную площадь, она и есть ответ.

Так как `m < n` и `k ≤ m`, в календаре всегда минимум две строки, поэтому первая и последняя строки не совпадают.

Размер сетки не больше примерно 200 клеток, так что перебор работает за доли секунды.

## Запуск

```bash
python3 solution_H.py < input.txt
```

Или вручную:

```bash
python3 solution_H.py
39 10 6
```
